# Glossário da Conexus

| Termo | Definição operacional |
|---|---|
| **Conexus** | Visão de empresa voltada a uma camada de inteligência e ação conectada aos sistemas empresariais existentes. |
| **Company OS** | Sistema de conhecimento, decisão, execução, cadência e governança usado para operar a Conexus. |
| **Founder Boardroom** | ChatGPT Project usado para debate estratégico e aconselhamento; não é a fonte oficial de decisões. |
| **Conexus HQ** | Repositório institucional versionado que preserva o conhecimento oficial da empresa. |
| **Wedge** | Problema inicial estreito usado para entrar no mercado e aprender antes de expandir a plataforma. |
| **Opportunity** | Problema ou possibilidade ainda não aprovada para execução. |
| **Initiative** | Esforço coordenado para produzir um resultado empresarial mensurável. |
| **Mission** | Unidade de execução com objetivo, escopo, critérios de aceite e resultado esperado. |
| **Evidence** | Informação observada que aumenta ou reduz a confiança em uma hipótese. |
| **Parked** | Deliberadamente fora da execução atual, sem ser descartado. |
| **Done** | Entregue ou testado, utilizado, medido, com aprendizado e decisão registrados. |
