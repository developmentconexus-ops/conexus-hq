# Roadmap Institucional Inicial

## Now — Company OS v0.1

- [x] Criar o repositório privado `conexus-hq`.
- [ ] Revisar e versionar o bootstrap institucional.
- [ ] Configurar o GitHub Project.
- [ ] Medir capacidade semanal.
- [ ] Completar o inventário do portfólio.
- [ ] Realizar a primeira weekly review.
- [ ] Escolher uma única iniciativa de produto permanente.

### Experimento bounded em paralelo — Imersão Mitra

- [x] Selecionar o experimento: **Conexus Sales Radar — Orçamentos em Risco & Next Best Action**.
- [ ] Construir somente a vertical slice aprovada durante a imersão.
- [ ] Usar dados reais ou extrato sanitizado de dados reais para evidência.
- [ ] Executar backtest histórico ou piloto quando viável.
- [ ] Registrar aprendizados e evidências.
- [ ] Realizar review `continue / reshape / park / stop` ao final da imersão.

Esta exceção é regida pelo [`ADR-0004`](../decisions/adr/ADR-0004-mitra-sales-radar-bounded-experiment.md) e não escolhe o primeiro wedge comercial definitivo.

## Next — Discovery da iniciativa permanente escolhida

- Definir problema, usuário e hipótese de valor.
- Coletar evidências.
- Definir métrica e critério de interrupção.
- Projetar o experimento mais barato.

Se o Sales Radar for promovido após a review da imersão, os aprendizados do experimento poderão satisfazer parte deste estágio; isso não é presumido antecipadamente.

## Later — Execução do primeiro ciclo de produto

- Implementar apenas o necessário para o experimento.
- Colocar em uso real.
- Medir resultado.
- Registrar aprendizado e decisão.

Datas institucionais serão adicionadas após a medição da capacidade real do fundador.
