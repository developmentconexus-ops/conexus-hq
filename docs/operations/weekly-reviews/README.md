# Weekly Reviews

Cada review deve registrar:

1. Compromissos da semana anterior.
2. Entregas e evidências.
3. Trabalho não concluído e causa.
4. Bloqueios.
5. Decisões tomadas.
6. Novas ideias capturadas sem mudança automática de prioridade.
7. Até três entregas da próxima semana.
8. Atualizações necessárias em `docs/NOW.md`.

Use [`templates/weekly-review.md`](../../../templates/weekly-review.md).
